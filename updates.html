Update Log

Stay up to date with patch notes, backend refactors, network optimizations, and physics improvements for Volleyball Revengers.

Build v0.4.2 — Proximity Hit Detection & Physics Refactor

August 2026
Physics Photon Fusion
  • Custom Collision Physics: Reverted ball collision and bounce physics logic to earlier custom implementations for enhanced predictability during jump serves and high-velocity spikes.
  • Proximity Hit Detection: Restored custom proximity hit detection scripts, ensuring accurate hand-to-ball contact registry on standalone Meta Quest hardware.
  • Multiplayer Sync: Fine-tuned Photon Fusion network state serialization to reduce jitter on high-speed ball trajectories during low-latency matches.

Build v0.4.0 — LIV Integration & Camera Mechanics

July 2026
LIV SDK PlayFab
  • LIV Camera Support: Full implementation of LIV VR capture SDK to support third-person spectator viewing, smoothing, and mixed reality content creation.
  • Stat Syncing: Integrated PlayFab Title Data and User Data pipelines for real-time tracking of aces, blocks, and overall player profile stats.
  • Input Polish: Optimized Quest controller velocity calculations for smoother float serve and jump serve tosses.

Build v0.3.5 — Photon Fusion Netcode Foundation

June 2026
Photon Fusion PlayFab
  • Netcode Migration: Core networking pipeline transitioned to Photon Fusion for ultra-low latency host/client synchronization across VR headsets.
  • PlayFab Authentication: Added seamless client login authentication using PlayFab custom IDs tied to player device profiles.
  • Basic Matchmaking: Implemented room creation, lobby Joining, and basic court positioning systems.
